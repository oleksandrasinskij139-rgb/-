LuxVisuals Admin: панель по адресу /admins/ (демо-режима нет).

Сервер: заменить app.py на Render и задать переменную ADMIN_PASSWORD. Без неё вход закрыт.
Ограниченные админы заходят по ссылке /admins/?invite=... (создаётся в панели, показывается один раз).
Права: полный админ может всё; ограниченный видит игроков и управляет игрой (FPS, клавиши, прыжок, чат, инвентарь, меню,
сообщение, закрытие), но без токенов, банов, флагов, массовых действий и управления админами.
Мод опрашивает сервер раз в секунду: команды доходят за 1–2 секунды, баланс и покупки применяются без перезапуска игры.
