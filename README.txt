LuxVisuals — сайт (этап 1.1: вход по токену подключён)

Что работает:
- account.html + auth.js: вход по токену (POST /api/site/login), сессия на 24 часа в sessionStorage.
- graffiti.html + graffiti.js: после входа показывает номер игрока, кнопку «Выйти», счётчик слотов. Список пока пустой, загрузка вернёт «появится на следующем этапе» (хранилище картинок ещё не подключено).
- index.html, rules.html — статические страницы.

Настройка:
1. config.js уже указывает на https://luxcosmetics-1.onrender.com. Если адрес сервера другой, поменяй его там.
2. Залей весь каталог на статический хостинг.
3. На сервере (Render) должен быть задеплоен новый app.py. По желанию задай переменную SITE_ORIGIN с адресом сайта (по умолчанию разрешены все).

Первый вход после простоя может занять до минуты: бесплатный Render просыпается.
